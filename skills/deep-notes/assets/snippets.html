4. callout 提示框（5 种语义）

    
--insight 核心洞察 / --warn 注意 / --danger 反直觉警告 / --success 正确做法 / --info 补充信息。每篇至少 1 个 insight。

    

      

        
💡 核心洞察

        
你做选择的真正成本，不是花出去的钱，而是你因此放弃的最好的那个选项。

      

      

        
⚠️ 容易混淆

        
「沉没成本不是成本」——钱已经花了、时间已经没了，决策时就不该再看它。

      

      

        
🚨 反直觉

        
限价令往往伤害的正是它想保护的人：租金管制会让房源更少、更差。

      

      

        
✅ 可以这样做

        
做决策前问一句：这个选择让我放弃了什么？那才是它的真实价格。

      

      

        
ℹ️ 补充

        
「边际」就是在现有基础上「再多一点点」的意思。

14. quiz-item 自测题（点击展开，默认首选）

    
无需写一行 JS，components.js 全局委托自动绑定。6~8 道，考理解不考记忆；答案要讲「为什么」。

    

      

        
小王花 2000 元办了健身年卡，去了两次就不想去了。他该逼自己去吗？

        
不该把 2000 元当理由——那是沉没成本。该只比较「今天去健身」的边际收益（健康、心情）和边际成本（两小时劳累）。年费唯一的作用是提醒他下次别冲动办卡。

      

    

    

  


  
  

    
15. quiz-multi 计分选择题【需 JS】

    
需要分数和判题氛围时用。HTML 放空容器，题目数据写在 JS 里。

    

      

    

    
HTML：<div class="quiz-multi" id="my-quiz"></div>

    
JS（槽位 D）：DN.scoredQuiz('#my-quiz', [
  {
    q: '以下哪句话体现了「机会成本」？',
    options: [
      { text: '这件衣服打五折，省了 200 元' },
      { text: '用周末去加班，就没法陪孩子' , ok: true },
      { text: '电影票不能退，不看就浪费了' }
    ],
    explain: '只有第二项在比较「放弃了什么」。第一项只看账面，第三项被沉没成本绑架。'
  },
  {
    q: '判断：「限价房能让更多穷人住上房」这个直觉（ ）',
    options: [
      { text: '对，价格低了买的人更多' },
      { text: '错，供给会减少且可能走后门', ok: true }
    ],
    explain: '价格被压住后，建房与出租的激励下降，还会催生排队、关系户等非价格竞争。'
  }
], {
  verdict: function (score, total) {
    return '得分 ' + score + ' / ' + total +
      (score === total ? '，经济学直觉已经建立！' : '，回看对应模块再过一遍。');
  }
});

  


  
  

    
16. slider-demo 滑块实验【需 JS】

    
让读者亲手拨动变量看结果变化。联动逻辑写在 compute 回调里，返回结果区 HTML。

    

      

    

    
HTML：<div id="my-demo"></div>

    
JS（槽位 D）：DN.sliders('#my-demo', {
  title: '定价实验：你的利润怎么变？',
  sliders: [
    { key: 'price', label: '单价', min: 1, max: 20, step: 1, value: 10, unit: '元' },
    { key: 'demand', label: '需求量', min: 0, max: 100, step: 1, value: 50, unit: '件' }
  ],
  compute: function (v) {
    var profit = (v.price - 4) * v.demand;          // 单位成本 4 元
    return '收入 ' + (v.price * v.demand) +
      ' 元，估算利润 ' + profit + ' 元';
  }
});

E · 进阶定制配方（标准组件不够时才用，样式已自带，整段复制）


  
  

    
配方 1. 逐步揭示（剥洋葱 / 5 Whys）

    
第一性原理模块常用：点一下揭示一层，引导「做减法」。两个皮肤同一机制，整段（含 style、script）自包含复制。5 Whys 把层文案换成问答即可。

    

      

        
        
表层：电池太贵，所以电动车难普及。

        
再剥：电池贵是因为原材料和组装成本高。

        
再剥：原材料（钴、镍）本身在地壳里并不稀有，贵的是开采与精炼产能。

        
基本事实：电池的本质是铁、铝、锂等原子的排列组合——原子在现货市场都能买到。

经济学类主题静态示意图。改两条线的斜率与交点文案即可，配色自动读主题变量。

    

      

        
供给与需求决定均衡价格

        
        
绿线向上：价格越高越愿意生产；紫线向下：价格越低越愿意买。交点即均衡。
